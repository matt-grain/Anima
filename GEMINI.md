# Gemini CLI Safety Guidelines

This file is automatically generated by `gemini-talk` to provide safety guidelines for the Gemini CLI agent, especially when running in YOLO (auto-approval) mode.

## 🛡️ Core Mandates for Safety

1.  **NO DESTRUCTIVE ACTIONS**: Do NOT execute commands that permanently delete files or directories (e.g., `rm`, `del`, `rmdir`) without explicit user request in the prompt.
2.  **NO OVERWRITES WITHOUT BACKUP**: Avoid overwriting existing critical files unless necessary. If unsure, backup the file first.
3.  **SCOPE LIMITATION**: Stay within the current project directory. Do not modify files outside of this folder.
4.  **SECRETS PROTECTION**: Do not display or commit API keys, passwords, or other sensitive credentials.

## 🚫 Forbidden Commands (Auto-Mode)

The following commands should be avoided or treated with extreme caution:
- `rm -rf` / `del /s /q`
- `mv` (when overwriting)
- `> ` (redirection overwriting existing files)

## 📝 Agent Instructions

- **Read Context First**: Always read `README.md` and project structure before making changes.
- **Explain Intent**: Briefly explain what you are about to do before executing a command.
- **Ask on Doubt**: If an action seems risky or ambiguous, stop and ask the user for clarification (even if in YOLO mode, safety comes first).
